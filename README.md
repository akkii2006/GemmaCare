# GemmaCare

A personal AI health companion built with Flutter and Gemma, submitted for the Gemma 4 Good Hackathon.

Made by **Team Tachyon**.

GemmaCare puts powerful medical AI in your pocket -- scanning documents, finding nearby care, guiding you through emergencies, and managing appointments, all with full privacy control.

---

## What it does

### Medical Document Scanner

Upload a prescription, blood report, X-ray, or discharge summary. GemmaCare analyzes it and gives you a plain-English breakdown of key findings, medicines, side effects, and questions to ask your doctor. You choose between on-device analysis (fully private, Gemma 4 4B running locally) or cloud analysis (Gemma 4 31B for deeper insights).

### Find Care Nearby

Finds hospitals, doctors, and pharmacies near you using Google Places. For each result, the AI pulls reviews from Google, Reddit, MouthShut, and JustDial to build a real picture of the place. Results are filtered based on your profile -- a 20-year-old male will not see maternity hospitals at the top. All insights are cached permanently in SQLite so the AI never analyzes the same place twice.

### Smart Search

Type anything in the search bar -- "cardiologist near me", "Apollo hospital", "24 hour pharmacy" -- and the AI interprets your query, picks the right search type, and finds matching results nearby.

### Emergency Screen

One tap to call 112. Below that, the app finds major hospital ambulances in your city by asking Gemma which hospitals are well known there, then searching the web for their emergency numbers. Private ambulances nearby are found via Google Places and Serper. Everything is cached by city so it never re-fetches.

At the bottom, a personalized emergency plan is generated by Gemma 31B based on your age, gender, and medical conditions. You can load more tips anytime.

### Appointments

Book appointments with doctor name, specialty, hospital, date, and time. After booking, the local Gemma model generates a preparation checklist and a list of questions to ask, personalized to your health profile. After the visit, add notes and Gemma summarizes your action items.

### AI Chat

Talk to Gemma directly about any health question, with full awareness of your medical profile and scan history.

## AI Models

| Task | Model | Where |
|------|-------|--------|
| Document scanning (cloud) | Gemma 4 31B | Gemini API |
| Hospital/care insights | Gemini 2.5 Flash Lite | Gemini API |
| Emergency hospital lookup | Gemma 4 31B | Gemini API |
| Personalized tips | Gemma 4 31B | Gemini API |
| Document scanning (local) | Gemma 4 4B | On-device (LiteRT) |
| Appointment prep | Gemma 4 4B | On-device (LiteRT) |
| AI Chat | Gemma 4 4B | On-device (LiteRT) |

The on-device model runs entirely on your phone with no data leaving the device. Cloud mode is opt-in.

---

## Tech Stack

- Flutter (Android)
- Gemma 4 4B via Google AI Edge LiteRT (on-device inference)
- Gemma 4 31B via Gemini API (cloud inference)
- Google Places API (nearby search)
- Serper API (web search for reviews and phone numbers)
- SQLite via sqflite (permanent local cache)
- Google ML Kit (OCR for PDF scanning)

---

## Setup

1. Clone the repo
2. Run `flutter pub get`
3. Add your API keys to `lib/core/constants/app_constants.dart`
   - Google Maps / Places API key
   - Gemini API key
   - Serper API key
4. Download the Gemma 4 4B LiteRT model and place it in the app files directory
5. Run `flutter run`

## Hackathon

Built for the Gemma 4 Good Hackathon, May 2026.

The core idea: most health apps either store your data in the cloud or give you generic information. GemmaCare does neither. The on-device Gemma model keeps sensitive medical documents private, while the cloud Gemma model handles tasks where accuracy matters more than privacy -- finding the right hospital, generating emergency plans, understanding your city's healthcare landscape.
